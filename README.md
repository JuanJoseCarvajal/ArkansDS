# MAI Natural Astro (nuevo repositorio base)

Landing y sitio informativo en **Astro** inspirado en la arquitectura de información de [mainatural.com](https://mainatural.com/), con copy mejorado para claridad comercial.

## Arquitectura
- `/` Home
- `/capilar`
- `/facial`
- `/corporal`
- `/tienda`
- `/agenda-tu-cita`
- `/quienes-somos`

## Ejecutar
```bash
npm install
npm run dev
```

## Crear repositorio remoto nuevo
Si quieres crear un repositorio remoto nuevo:
1. Crea repo vacío en GitHub/GitLab
2. Ejecuta:
```bash
git remote remove origin
git remote add origin <URL-DEL-REPO-NUEVO>
git push -u origin <branch>
```
